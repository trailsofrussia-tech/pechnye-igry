# Интерактивы Музея Печи

Семь HTML-игр для страницы https://pechmuseum.ru/pechnye-igry.

1. Гонка шести печей.
2. Собери кирпичную голландку.
3. День крестьянина у печи.
4. Что готовили в печи.
5. Алхимия печи.
6. Реставратор и мастер изразцов.
7. Путь печника.

Сайт размещается через GitHub Pages и встраивается в Tilda. Откройте index.html для локального запуска. На игровых страницах есть возврат к подборке и ссылка на музей.

Мобильное обновление от 7 сентября 2026 года: новая глинобитная печь, компактные рецепты, фактурная полка алхимии и книга открытий, исправленная сборка изразца и обжиг мехами с десятисекундной выдержкой.

Все температуры и скорости в играх — условные параметры учебных моделей, а не инструкции по сооружению и эксплуатации настоящей печи.
